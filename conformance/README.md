# Connect conformance

Runs the official [connectrpc/conformance](https://github.com/connectrpc/conformance) suite in client mode against a `ConformanceServiceClient` generated by protoc-gen-connect-ruby, so both the plugin's output and the connect_rpc_httpx runtime are under test.

The suite is scoped by [`config.yaml`](config.yaml) to what the runtime implements: the Connect protocol, unary RPCs over POST and GET, client and server streams and half-duplex bidirectional streams, the proto and JSON codecs, over HTTP/1.1, cleartext HTTP/2 and TLS (with client certificates). Full-duplex bidirectional streams, gRPC, gRPC-Web and compression are out of scope.

## Current result

```
812 passed, 0 failed
(Another 64 failed as expected due to being known failures/flakes.)
```

The known failures, listed in [`known_failing.txt`](known_failing.txt), are the client cancellation cases. A call blocks its thread and the client has no API to cancel it from another. Leaving a stream's iteration does cancel it, but the suite expects the call to carry on after the cancellation and report it.

## Run

```sh
mise run conformance
```

which is `bundle exec rake conformance` with buf and the runner from mise. The task regenerates `gen/` (git-ignored) from the BSR module matching the runner version pinned in `mise.toml`, then runs the suite. Exit 0 means every in-scope case passed.

To inspect an exchange, run the runner by hand:

```sh
mise x -- connectconformance --trace --mode client --conf conformance/config.yaml \
  --known-failing @conformance/known_failing.txt -- bundle exec ruby conformance/client.rb
```

## Files

- `client.rb`: the client-under-test. Reads `ClientCompatRequest`s on stdin, issues each through the generated client on a pool of threads that share httpx sessions, and writes `ClientCompatResponse`s to stdout.
- `buf.gen.yaml`: generates the conformance messages with protoc's Ruby generator and the client with protoc-gen-connect-ruby.
- `config.yaml`: the features the suite exercises.
- `known_failing.txt`: cases expected to fail, with the reason.
